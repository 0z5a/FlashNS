# CUDA v2 首个融合原型：A5000 实测

2026-09-08。新增代码实现了 `D @ W → tanh jet VJP`，并完成局部、完整参数梯度、十步固定 SGD 和四种 Sanitizer 检查。本次布局减少了 `barH` 物化与峰值分配，但没有显示可归因于融合的稳定速度收益。因此保留库 GEMM 默认路径，融合维持实验入口。

`B=16384、C=64` 的完整梯度从 111.58 ms 降到 99.74 ms，九轮配对中位倍率为 1.119×；相同 CUTLASS 主循环加独立 VJP 为 99.45 ms。这个收益来自替换 GEMM，本轮没有证据把它归因于融合。其他三个完整网络尺寸中，融合均未超过库基线。

## 数学与线程布局

full-Taylor 二维 Q=10、三维 Q=20 均采用 `partial^alpha / alpha!`。JetSpec 固定系数顺序、原始导数恢复和 seed 的转置映射；一阶参数反传不额外除以 Q。当前 H-only tanh 导数策略与 v1 一致，未改变精度以改善性能。HVP、double backward、C13 等未实现能力显式拒绝。

CTA 采用 CUTLASS 64×64×16 主循环、32×32×16 warp tile、三阶段载入；128 个线程完整归约 Cout，随后把 accumulator 写入 shared memory，按完整 `(sample, channel)` 的 jet 分配 VJP 所有权。二维每个 CTA 容纳 6 个样本，三维容纳 3 个样本，均使用 60/64 个逻辑行。长 batch 的行填充开销约 6.7%；没有将 Q=20 补为 32。

VJP 前等待主循环异步复制完成并执行 CTA 同步，重用 shared-memory union 后再次同步。输出 `Dprev` 继续写回，供独立 wgrad 和下一次 dgrad 使用。没有 split-K 或全局 workspace；输出新分配，C ABI 拒绝别名及非法尺寸。stream 生命周期和输入就绪责任见实验说明。

## 正确性与边界

CPU 测试共 38 项通过。GPU 数值阈值在计时之前固定为 `2e-12 + 2e-11 * abs(reference)`，所有比较使用这一阈值。

- 24 组局部检查：二维/三维、零输入、带正负值的随机输入、混合尺度、B/C 不整除 tile。独立 Torch AD 求激活 VJP；最大绝对误差约 5.46e-12，最大误差/容差比约 0.02573，小于 1。
- 两组非默认 stream 测试，每组重复执行四次；验证空 tensor、非法 dtype/布局/形状和不支持的求导模式。
- 三个二维 `2→8→7→3` 网络、B=5、坐标尺度 0.01/0.4/3.0：全部三阶输出 jet、稳态 NS residual 加 residual-gradient loss 和所有参数梯度与独立嵌套 AD 对照通过。参数梯度最大绝对误差约 1.39e-17。
- 24 个计时尺寸和四个完整梯度尺寸逐个完成同输入数值比较。
- 十步固定 SGD，B=128、`2→32→32→3`、学习率 1e-3：三条路径每步 loss、全部梯度及最终参数一致。loss 从 0.08514818 降到 0.07440387。这只是相同有限更新过程的检查，没有科学求解停止标准；优化器不计入下面的完整梯度时间。

独立 C++ smoke 包含 36 个数值用例，各重复三次；检查输出前后 canary、非默认 stream、空调用、非法参数与 alias。最终实测共享库的 memcheck、racecheck、initcheck、synccheck 均返回 0；racecheck 为 0 errors、0 warnings。该有限测试不能替代形式化证明。

饱和区失败仍保留在原始报告的 `saturation`：例如 z=20 时，H 的零阶舍入为 1，H-only 策略丢失真实非零的极小导数。没有把这些失败改标为通过。当前成功范围限于列出的普通 FP64 输入；鲁棒尾部需要额外状态或从 Z 重算并独立验收。

## 完整梯度步骤

三条路径只有 dgrad/VJP 实现不同：B1 是 packed 库 GEMM + v1 原生 VJP；U 是同一 CUTLASS 主循环 + v1 原生 VJP；F 是融合版本。forward、wgrad、bias、loss、输出 seed 和表示/精度固定。时间包含所有这些步骤，不含编译、CPU 独立验收、数据载入或优化器。

每条路径预热三次，九轮旋转/反转执行顺序，记录同步 wall time。下面时间是各路径中位数，倍率是逐轮配对倍率的中位数，二者不必恰好相除。profile 在不带 profiler 的计时完成后单独采集。

|---:|---:|---:|---:|---:|---:|---:|
| 4096 | 32 | 12.536 | 14.011 | 13.551 | 0.893× | 1.000× |

## 本轮决策与后续边界

保留 B1 默认路径。已实现的 F 提供可替换、经过验收的融合入口和显存节省证据；当前不作为速度优化默认启用。U 同时保留，避免后续把 GEMM 算法变化计为融合收益。B1 是当前 Torch/cuBLAS 默认 packed dispatch，未声称做过穷尽的 cuBLASLt 计划搜索。

下一步适合先做有限 tile/所有权搜索，尤其是 C=32 和 Cout=3 的反例；再评估完整梯度，保持精度和 Q 不变。根据现有 profile，wgrad 与 loss/seed 也需要单独分析。当前 A5000 足以继续这些实验；换数据中心 GPU 时应对三条路径重新测量，不能沿用本机倍率。

C13、HVP、饱和区稳健重建、首尾层特化、完整科学训练和求解到统一停止条件仍未完成。这些是后续工作，不能由本轮有限数值通过或十步 SGD 推出已经完成。
